# Kend et rensdyr

NFC-post til FDF natteløbet "Rensdyrets hævn". Kører i Chrome på Android (Web NFC).

- Opsætning: `/#opsaetning` – scan tags i den rigtige rækkefølge
- Spil: `/#spil` – patruljen scanner, forkert rensdyr = start forfra

Deployes automatisk til Azure Static Web Apps ved push til `main`.
